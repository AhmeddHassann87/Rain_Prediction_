# Rain Tomorrow Predictor

A small end-to-end ML project: train a Random Forest classifier on a weather dataset in a
Jupyter notebook, save the trained model, and serve predictions through an interactive
Streamlit app.

## Project structure

├── Rain_Prediction.ipynb    # Training notebook — cleans data, trains & evaluates the model, saves rain_model.pkl
├── rain_prediction_app.py   # Streamlit app — loads rain_model.pkl and serves live predictions
├── rain_model.pkl           # Generated by the notebook (not included — see below)
├── requirements.txt
└── README.md

## What the model predicts

Given today's weather conditions (season, temperatures, humidity, pressure, wind speed,
cloud cover, precipitation, and whether it rained today), the model estimates the
probability that it will rain **tomorrow** ("Yes"/"No"), using a `RandomForestClassifier
(300 trees, max depth 6).

> This is trained on a small/synthetic dataset for learning purposes — treat predictions as
> a demo, not a real forecast.

## Setup

1. **Clone / download** this project folder.

2. **Create a virtual environment** (recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   ```

3. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

## Step 1 — Train the model (run the notebook)

`Rain_Prediction.ipynb` currently loads its source data from a **local, hard-coded path**:

```python
df = pd.read_excel(r"C:\Users\HP\Desktop\weather_dataset.xlsx")
```

Before running the notebook, update this path to point to your copy of
weather_dataset.xlsx` (or place the file at that exact path).

Then run all cells in order:

```bash
jupyter notebook Rain_Prediction.ipynb
```

The notebook will:
1. Load and clean the weather dataset (fill missing numeric values with the median, label-encode `Season`, `RainToday`, `RainTomorrow`).
2. Split the data into train/test sets (80/20, stratified).
3. Train a `RandomForestClassifier` and print accuracy + a classification report.
4. Plot a confusion matrix and feature-importance chart.
5. **Save `rain_model.pkl`** — a bundle containing the trained model, the three label encoders (`le_season`, `le_raintoday`, `le_target`), and the feature column order.
6. Run a quick sanity check by reloading `rain_model.pkl` from disk and making one prediction.

Make sure `rain_model.pkl` ends up in the **same folder** as `rain_prediction_app.py`
before moving to Step 2.

## Step 2 — Run the Streamlit app

```bash
streamlit run rain_prediction_app.py
```

This opens a browser tab where you can:
- Adjust today's conditions (season, temperatures, humidity, pressure, wind speed, cloud cover, precipitation, rain today) in the sidebar.
- Click **Predict** to see whether rain is expected tomorrow, along with the model's confidence and a full probability breakdown chart.
- Expand **"Show the exact values being sent to the model"** to inspect the encoded feature row.

## Notes

- The app expects the pickle bundle to contain exactly these keys: `model`, `le_season`, `le_raintoday`, `le_target`, `feature_cols`. If you retrain with different features or encoders, keep the bundle shape consistent or update `rain_prediction_app.py` accordingly.
- `openpyxl` is required for `pandas.read_excel()` to read `.xlsx` files — it's included in `requirements.txt`.
- If you deploy the app (e.g. Streamlit Community Cloud), commit `rain_model.pkl` alongside the app, or add a step to your deployment pipeline that runs the notebook/training script first.
